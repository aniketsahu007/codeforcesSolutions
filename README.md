# Codeforces Solutions

This repository contains C++ solutions for various Codeforces problems.
Each source file is a standalone solution intended to be compiled and run individually.

## Tech Stack

- Language: C++
- Typical compiler: `g++`

## How to Compile and Run

From `/home/runner/work/codeforcesSolutions/codeforcesSolutions`:

```bash
g++ -std=c++17 71A.cpp -o 71A
./71A
```

Replace `71A.cpp` with any other solution file.
